# Projetos alternativos

Esta pasta reúne conceitos de países fictícios e linhas de história alternativa independentes do cânone principal de **Valga–Valka**.

## Regra de separação

- Nada registrado nesta pasta altera automaticamente o cânone de Valga–Valka.
- Cada nova região ou país deve possuir sua própria subpasta.
- Ideias, cronologias, personagens, fronteiras e retcons de um projeto não devem ser misturados com os de outro.
- Um elemento só passa de um projeto para outro mediante decisão explícita do autor.
