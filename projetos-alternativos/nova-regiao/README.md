# Nova região — conceito separado

Status: **em desenvolvimento**.

Este diretório é reservado para uma nova ideia de país/região fictícia e permanece totalmente separado do cânone de Valga–Valka.

## Princípios provisórios

- A região ainda não foi definida.
- Nenhuma fronteira, data, regime, personagem ou cronologia está fixada.
- Somente elementos aprovados explicitamente pelo autor devem ser tratados como cânone deste projeto.
- Figuras históricas reais não serão automaticamente apropriadas como personagens nacionais; isso será decidido caso a caso conforme o conceito for desenvolvido.

## Próximos elementos a registrar

- região escolhida;
- ponto de divergência;
- território inicial;
- nome provisório/oficial;
- população e identidade linguística;
- regime político;
- cronologia.
